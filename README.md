# عيادة نور | The Clinic

نظام حجز مواعيد تجريبي لعيادة أسنان: اختيار الخدمة واليوم والساعة، ثم تأكيد الحجز بكود OTP (محاكاة). يدعم العربية (RTL) والـ Dark Mode.

🔗 **Live Demo:** https://blackclover000.github.io/the-clinic/

![Home](images/لقطة%20شاشة%202026-10-22%20142412.png)

## المميزات
- 4 خدمات بمدة وسعر، ومتطلبات ما قبل الموعد لكل خدمة
- أيام متاحة تتولد تلقائياً (بدون الجمعة)، وساعات من 10 ص حتى 7 م
- منع الساعات المنتهية والمحجوزة
- ملخص حجز لحظي بجانب النموذج
- تحقق من البيانات (الاسم، رقم موبايل مصري)
- تأكيد الحجز بكود من 4 أرقام (محاكاة SMS)
- إلغاء الحجز وإعادة إتاحة الموعد
- Accessibility: ARIA وتنقل بالكيبورد، وتعقيم المدخلات

## التقنيات
HTML5 · CSS3 (Grid, Flexbox, Variables) · Vanilla JavaScript
